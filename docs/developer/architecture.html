Architecture Overview

System Overview​

Helix Orchestration is a two-tier distributed platform for coordinating scientific instruments in laboratory fumehoods. The Agent tier runs one process per fumehood - it owns local execution, device control, and safety enforcement. The Site Server tier operates site-wide: it compiles WSL workflows, manages campaigns, and provides the external REST and gRPC API.

Within each process the codebase follows Clean Architecture: the Core domain library has no outward dependencies; infrastructure projects depend inward. Subsystem boundaries are enforced by project structure and interfaces rather than runtime checks, making it straightforward to swap backends (simulation versus real hardware) at DI registration time.

Key Concepts​

ConceptLayerDescription
RunspaceDefinitionContractsCompiled execution contract produced by the WSL compiler; JSON; consumed by Agent
DurableRunspaceAgentOne workflow instance container with its own ExperimentContext, device leases, and durable Cleipnir continuation state
WorkflowContextCoreThe single DI surface injected into a workflow -- carries Capabilities, Trends, Safety, State, Experiment
ICapabilityInvoker / CapabilityRegistryCore / AgentDispatches named capability verbs (e.g. SetTemperature) to the correct device adapter; workflows never see device protocols
WSL (Workflow Specification Language)ContractsJSON declarative authoring format; generated by UI, chatbot, ELN, or ML; compiled at Site Server to RunspaceDefinition
IAgentProxySiteServerSeam between Site Server and Agent -- SimAgentProxy for dev/test, GrpcAgentProxy for production
ITrendProviderCoreTyped accessors for all trend kinds (scalar, spectral, diode array, image, video, derived)
ISafetyEngineCoreEvaluates InterlockRule predicates; triggers EmergencyStopToken on critical violations
ExperimentContextCoreLifecycle state machine (Created to Running to Suspended to Completed/Failed); every measurement tagged with ExperimentId
CampaignSiteServerSite Server-owned multi-experiment orchestration unit (DoE grids, ML loops, sweeps); agents execute one experiment at a time
