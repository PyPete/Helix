# Sketch 001: Ribbon + Workspace Shell

## Design Question
What should the top-level chrome of the Helix Desktop app feel like?

## How to View
Open `.planning/sketches/001-ribbon-workspace-shell/index.html` in a browser.

## Variants
- **A: Dense VS-Ribbon** ★ — Full Ribbon with large icon buttons grouped by function, tab strip above. Closest to Visual Studio / Office Ribbon.
- **B: Figma-style bar** — Single slim topbar, centered tool icons, no Ribbon tab strip.
- **C: Compact Menu+Toolbar** — Classic menu bar + single toolbar row of small icon buttons.

## Winner
**Variant A** — Dense VS-Ribbon. Provides the most discoverable surface for lab power users; grouping by Execution / Open Panel / Workspace / Devices maps directly to workflow phases.
