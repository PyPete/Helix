# Sketch Manifest

## Design Direction
Visual Studio / JetBrains–style IDE layout for a lab automation desktop app. Dark, dense, professional — the feel of a scientific instrument's software, not a consumer SaaS product. Primary audience: scientists who are power users comfortable with tool-heavy UIs. The Ribbon provides global controls; the docking workspace gives flexible, saveable layouts.

## Reference Points
- Visual Studio Code (activity bar + split panels + document tabs + bottom output)
- JetBrains Rider/IntelliJ (dock groups with tab strips, tool windows)
- Figma (floating panels, icon strip)
