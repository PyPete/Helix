# Phase 12 Plan 2: Agent Experiment Lifecycle

**Phase:** 12 - Experiment as Top-Level Scope
**Wave:** 2
**Status:** Complete

## Goal

Wire the full server-side experiment lifecycle into the Agent: add `ExperimentId` and `ExperimentPhase` correlation fields to `RunspaceEvent`, introduce the `IExperimentEventChannel` (second channel) so the persistence worker never starves the broadcast loop, create `IExperimentManager` / `ExperimentManager` for lifecycle state, build `ExperimentEventPersistenceWorker` to drain events to the DB, expose the seven `ExperimentEndpoints`, enrich `ManualActionEvent` with experiment context from `DeviceEndpoints`, and wire everything into `Program.cs`. When this plan completes, `POST /experiments` creates a traceable ExperimentId and all automated and manual events for that experiment are stored in `experiment_events`.

## Prerequisites

- Plan 1 (Wave 1) must be complete: `experiment_events` table exists, `IExperimentEventRepository` is registered, `ExperimentPhase` enum is in Core, `ExperimentRecord.ExperimentId` field is present.

2. Create `Helix.Orchestration.Agent/Experiments/ExperimentManager.cs`. Key design rules:
   - Store contexts in `ConcurrentDictionary<string, ExperimentContext>`.
   - `_activeExperimentId` field: `volatile string? _activeExperimentId`. Set when `StartAsync` succeeds; cleared when `CompleteAsync` or `AbortAsync` is called.
   - Constructor primary constructor: `ExperimentManager(IRunspaceEventEmitter emitter, ILogger<ExperimentManager> logger)` — `IRunspaceEventEmitter` **must be listed explicitly** as a constructor parameter; it is what `_emitter` resolves to (registered as singleton in Program.cs).
   - `StartAsync`: generate `experimentId = Guid.NewGuid().ToString("N")`, create `ExperimentContext` with `Lifecycle = Running`, `ActivePhase = Main`, `CreatedAt = DateTimeOffset.UtcNow`. Store in dictionary. Set `_activeExperimentId`. Call `_emitter.Publish(new ExperimentStartedEvent(experimentId, request.Name))`. Call `_emitter.Publish(new ExperimentPhaseChangedEvent(experimentId, "main"))`. For Phase 12, the runspace is started by `ExperimentEndpoints`, not `ExperimentManager` directly â€” ExperimentManager stores the context; the endpoint calls `IRunspaceManager.CreateAsync` separately and then calls a `SetActiveRunspace(experimentId, runspaceId)` method (add this to the interface).
   - `PauseAsync`: update the context record in the dictionary to `Lifecycle = Suspended`. Callers (ExperimentEndpoints) are responsible for pausing the active runspace via `IRunspaceManager`.
   - `ResumeAsync`: update to `Lifecycle = Running`.
   - `AbortAsync`: update to `Lifecycle = Failed`. Clear `_activeExperimentId`. Publish `ExperimentFailedEvent`.
   - `CompleteAsync`: update to `Lifecycle = Completed`. Clear `_activeExperimentId`. Publish `ExperimentCompletedEvent`.
   - `GetActive()`: returns `_activeExperimentId != null ? Get(_activeExperimentId) : null`.
   - `ExperimentContext` is a record (immutable); use `with` to produce updated copies when transitioning lifecycle state, then replace the dictionary entry using `TryUpdate` or re-`TryAdd`.

3. Create `Helix.Orchestration.Agent/Experiments/ExperimentEventPersistenceWorker.cs`. Follow the `BackgroundService` pattern already established by `LeaseExpiryWorker` and the `BroadcastLoopAsync` pattern from `AgentService.cs`:

   ```csharp
   public sealed class ExperimentEventPersistenceWorker(
       IExperimentEventChannel channel,
       IServiceScopeFactory scopeFactory,
       ILogger<ExperimentEventPersistenceWorker> logger) : BackgroundService
   {
       protected override async Task ExecuteAsync(CancellationToken stoppingToken)
       {
           await foreach (var evt in channel.Events.ReadAllAsync(stoppingToken))
           {
               try
               {
                   await using var scope = scopeFactory.CreateAsyncScope();
                   var repo = scope.ServiceProvider.GetRequiredService<IExperimentEventRepository>();
                   await repo.AppendAsync(MapToRecord(evt), stoppingToken);
               }
               catch (Exception ex)
               {
                   logger.LogWarning(ex, "Failed to persist experiment event {Type}", evt.Type);
               }
           }
       }

       private static ExperimentEventRecord MapToRecord(RunspaceEvent evt) => new(
           SequenceNum: 0,   // BIGSERIAL â€” ignored by INSERT; DB assigns
           ExperimentId: evt.ExperimentId!,
           Phase: evt.ExperimentPhase ?? "none",
           EventType: evt.Type,
           RunspaceId: evt.RunspaceId ?? "",
           StepId: evt is StepStartedEvent ss ? ss.StepId : evt is StepCompletedEvent sc ? sc.StepId : null,
           StepLabel: evt is StepStartedEvent ssl ? ssl.StepLabel : null,
           IsManual: evt is ManualActionEvent,
           DeviceId: evt is ManualActionEvent ma ? ma.DeviceId : null,
           Capability: evt is ManualActionEvent mac ? mac.Capability : null,
           ParametersJson: evt is ManualActionEvent map
               ? System.Text.Json.JsonSerializer.Serialize(map.Parameters) : null,
           ResultJson: evt is ManualActionEvent mar && mar.Result != null
               ? System.Text.Json.JsonSerializer.Serialize(mar.Result) : null,
           OccurredAt: evt.Timestamp
       );
   }
   ```

   The `IServiceScopeFactory` pattern is required because `IExperimentEventRepository` is registered as `Scoped` in Infrastructure â€” the worker (singleton lifetime) must not hold a scoped service directly.
