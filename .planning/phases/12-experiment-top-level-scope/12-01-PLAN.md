# Phase 12 Plan 1: Database + Core Model

**Phase:** 12 - Experiment as Top-Level Scope
**Wave:** 1
**Status:** Complete

## Goal

Lay the immovable foundation that all Agent-side work depends on: add `experiment_id` as an independent stable identity to the `experiments` table, create the append-only `experiment_events` table with its index, define the `ExperimentPhase` enum in Core, and wire the new `IExperimentEventRepository` into the Infrastructure DI extension. Every subsequent wave reads from or writes to these artifacts; nothing in waves 2 or 3 can proceed until these exist.

## Prerequisites

- None. This is the blocking foundation for the entire phase.

### Task 1: Database Migration — experiment_id column + experiment_events table

**Type:** migrate

**Files:**
- `postgres/migrations/002_experiment_events.sql` — create: migration script adding `experiment_id` to `experiments` and creating the `experiment_events` table

**Steps:**

1. Create `postgres/migrations/002_experiment_events.sql` with the following SQL:

   - ALTER TABLE `experiments`: add column `experiment_id TEXT NOT NULL DEFAULT ''`. Because `runspace_id` is the existing PK (used by `PostgresExperimentRepository.SaveAsync` with `ON CONFLICT (runspace_id)`), keep it as PK for backward compatibility. Add `experiment_id` as a new column. Backfill existing rows: `UPDATE experiments SET experiment_id = runspace_id WHERE experiment_id = ''`. Add a unique index: `CREATE UNIQUE INDEX IF NOT EXISTS ix_experiments_experiment_id ON experiments(experiment_id)`.

   - Create table `experiment_events`:
     ```sql
     CREATE TABLE IF NOT EXISTS experiment_events (
         sequence_num    BIGSERIAL       PRIMARY KEY,
         experiment_id   TEXT            NOT NULL,
         phase           TEXT            NOT NULL DEFAULT 'none',
         event_type      TEXT            NOT NULL,
         runspace_id     TEXT            NOT NULL DEFAULT '',
         step_id         TEXT            NULL,
         step_label      TEXT            NULL,
         is_manual       BOOLEAN         NULL,
         device_id       TEXT            NULL,
         capability      TEXT            NULL,
         parameters_json JSONB           NULL,
         result_json     JSONB           NULL,
         occurred_at     TIMESTAMPTZ     NOT NULL
     );
     CREATE INDEX IF NOT EXISTS ix_experiment_events_experiment_id
         ON experiment_events(experiment_id, sequence_num);
     ```

   - Do NOT add a foreign key from `experiment_events.experiment_id` to `experiments` in this migration. The `experiments` table currently has `runspace_id` as PK; a FK to `experiment_id` would require the unique index to exist first and could fail on empty-string default rows. Leave referential integrity enforcement to application code in Phase 12.

2. Verify the script is idempotent: all DDL uses `IF NOT EXISTS`. The `ALTER TABLE ... ADD COLUMN` must be guarded:
   ```sql
   DO $$
   BEGIN
     IF NOT EXISTS (
       SELECT 1 FROM information_schema.columns
       WHERE table_name='experiments' AND column_name='experiment_id'
     ) THEN
       ALTER TABLE experiments ADD COLUMN experiment_id TEXT NOT NULL DEFAULT '';
       UPDATE experiments SET experiment_id = runspace_id WHERE experiment_id = '';
     END IF;
   END $$;
   ```

3. Apply the migration against the development database:
   ```
   psql -U helix -d helix_orchestration -f postgres/migrations/002_experiment_events.sql
   ```
   (or via `docker compose exec db psql -U helix -d helix_orchestration -f /migrations/002_experiment_events.sql` if using the compose stack)

**Verification:**
```
psql -U helix -d helix_orchestration -c "\d experiments" | grep experiment_id
psql -U helix -d helix_orchestration -c "\d experiment_events"
```
Both queries must return results without error. The `experiment_events` table must show `sequence_num`, `experiment_id`, `phase`, `event_type`, `occurred_at` columns. The `experiments` table must show `experiment_id` column.

### Task 2: ExperimentPhase enum + ExperimentEventRecord + IExperimentEventRepository

**Type:** implement

**Files:**
- `Helix.Orchestration.Core/Experiment/ExperimentPhase.cs` — create: `ExperimentPhase` enum with `Pre`, `Main`, `Post` values
- `Helix.Orchestration.Infrastructure/Persistence/IExperimentEventRepository.cs` — create: interface + `ExperimentEventRecord` DTO
- `Helix.Orchestration.Infrastructure/Persistence/PostgresExperimentEventRepository.cs` — create: Dapper implementation

**Steps:**

1. Create `Helix.Orchestration.Core/Experiment/ExperimentPhase.cs`:
   ```csharp
   namespace Helix.Orchestration.Core.Experiment;

   /// <summary>
   /// Identifies the lifecycle phase scope of an experiment run.
   /// Pre runs setup steps; Main runs the primary workflow; Post runs teardown.
   /// </summary>
   public enum ExperimentPhase
   {
       Pre,
       Main,
       Post
   }
   ```
   Pattern reference: `Helix.Orchestration.Core/Experiment/ExperimentLifecycle.cs` — copy the namespace and enum layout exactly.

2. Create `Helix.Orchestration.Infrastructure/Persistence/IExperimentEventRepository.cs`. The interface must have three methods:
   - `Task AppendAsync(ExperimentEventRecord record, CancellationToken ct = default)` — INSERT only (no upsert; audit integrity requires immutable rows)
   - `Task<IReadOnlyList<ExperimentEventRecord>> GetByExperimentIdAsync(string experimentId, CancellationToken ct = default)` — returns all events, ordered by `sequence_num ASC`
   - `Task<IReadOnlyList<ExperimentEventRecord>> GetReplayLogAsync(string experimentId, CancellationToken ct = default)` — same as `GetByExperimentIdAsync` but semantically named for I5 replay

   The `ExperimentEventRecord` sealed record (co-located in the same file) must carry: `long SequenceNum`, `string ExperimentId`, `string Phase`, `string EventType`, `string RunspaceId`, `string? StepId`, `string? StepLabel`, `bool? IsManual`, `string? DeviceId`, `string? Capability`, `string? ParametersJson`, `string? ResultJson`, `DateTimeOffset OccurredAt`.

3. Create `Helix.Orchestration.Infrastructure/Persistence/PostgresExperimentEventRepository.cs`. Follow the `PostgresExperimentRepository` pattern exactly:
   - Constructor primary constructor: `PostgresExperimentEventRepository(DbConnectionFactory connectionFactory)`
   - `AppendAsync`: INSERT into `experiment_events` with all columns except `sequence_num` (BIGSERIAL, DB-assigned). Use `CommandDefinition` with CancellationToken. Use `jsonb` cast for `parameters_json` and `result_json` columns: `@ParametersJson::jsonb`. Map the C# record fields to snake_case SQL parameters using an anonymous object or a private row class.
   - `GetByExperimentIdAsync` and `GetReplayLogAsync`: `SELECT ... FROM experiment_events WHERE experiment_id = @experimentId ORDER BY sequence_num ASC`. Map rows via a private `ExperimentEventRow` class with `ToRecord()` method, following the `ExperimentRow` pattern in `PostgresExperimentRepository`.

4. Add DI registration in `Helix.Orchestration.Infrastructure/Persistence/InfrastructureServiceExtensions.cs`. In `AddHelixInfrastructure`, add:
   ```csharp
   services.AddScoped<IExperimentEventRepository, PostgresExperimentEventRepository>();
   ```
   Place it directly after the existing `AddScoped<ICampaignRepository, ...>` line.

dotnet build Helix.Orchestration.Core/Helix.Orchestration.Core.csproj
