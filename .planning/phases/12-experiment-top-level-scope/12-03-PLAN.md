# Phase 12 Plan 3: helix-desktop Frontend

**Phase:** 12 - Experiment as Top-Level Scope
**Wave:** 3
**Status:** Complete

## Goal

Surface the experiment lifecycle in helix-desktop: extend `agent.ts` types and `useAgentWebSocket` to carry experiment events, add a `useExperiment` hook that calls `POST /experiments` and lifecycle endpoints, migrate `ExecutionPanel` to call experiment endpoints instead of runspace endpoints, build the `ExperimentTimeline` dock panel with scope nesting and manual action markers, register it in `WorkspaceLayout`, and update all tests so the full suite passes. When this plan completes, a scientist can start an experiment from the desktop and watch events stream in real time in the Timeline dock.

## Prerequisites

- Plan 2 (Wave 2) must be complete: `POST /experiments`, `GET /experiments/{id}`, `POST /experiments/{id}/abort`, `POST /experiments/{id}/pause`, `POST /experiments/{id}/resume`, `GET /experiments/{id}/replay` all respond correctly. The WebSocket broadcasts `experiment-started`, `experiment-phase-changed`, `experiment-completed`, `experiment-failed`, and `manual-action` (with `experimentId`) frames.
- **I2 scope note**: Phase 12 delivers `Main` phase only. Pre and Post phase runspace sequencing (and the `ExperimentPhaseChangedEvent` values `"pre"` / `"post"`) are Phase 13 deliverables. The `ExperimentPhase` enum exists in Core with all three values; only `Main` is exercised end-to-end in Phase 12.

3. Create `helix-desktop/src/hooks/useExperiment.ts`. Follow the `useAgentHealth.ts` pattern (useState + async fetch functions returned from hook):

   ```typescript
   import { useState, useCallback } from "react";
   import type { ExperimentRecord } from "../types/agent";

   export interface UseExperimentResult {
     experimentId: string | null;
     activePhase: string | null;
     isRunning: boolean;
     startExperiment: (name?: string) => Promise<string | null>;
     pauseExperiment: () => Promise<void>;
     resumeExperiment: () => Promise<void>;
     abortExperiment: () => Promise<void>;
     error: string | null;
   }

   export function useExperiment(baseUrl: string): UseExperimentResult {
     const [experimentId, setExperimentId] = useState<string | null>(null);
     const [activePhase, setActivePhase] = useState<string | null>(null);
     const [isRunning, setIsRunning] = useState(false);
     const [error, setError] = useState<string | null>(null);

     const startExperiment = useCallback(async (name?: string): Promise<string | null> => {
       setError(null);
       try {
         const res = await fetch(`${baseUrl}/experiments`, {
           method: "POST",
           headers: { "Content-Type": "application/json" },
           body: JSON.stringify({ name: name ?? "Experiment" }),
         });
         if (!res.ok) { setError("Failed to start experiment: " + res.statusText); return null; }
         const data: ExperimentRecord = await res.json();
         setExperimentId(data.experimentId);
         setActivePhase(data.activePhase);
         setIsRunning(true);
         return data.experimentId;
       } catch (e) {
         setError((e as Error).message);
         return null;
       }
     }, [baseUrl]);

     const pauseExperiment = useCallback(async () => {
       if (!experimentId) return;
       await fetch(`${baseUrl}/experiments/${experimentId}/pause`, { method: "POST" });
       setIsRunning(false);
     }, [baseUrl, experimentId]);

     const resumeExperiment = useCallback(async () => {
       if (!experimentId) return;
       await fetch(`${baseUrl}/experiments/${experimentId}/resume`, { method: "POST" });
       setIsRunning(true);
     }, [baseUrl, experimentId]);

     const abortExperiment = useCallback(async () => {
       if (!experimentId) return;
       await fetch(`${baseUrl}/experiments/${experimentId}/abort`, { method: "POST" });
       setIsRunning(false);
       setExperimentId(null);
       setActivePhase(null);
     }, [baseUrl, experimentId]);

     return { experimentId, activePhase, isRunning, startExperiment, pauseExperiment, resumeExperiment, abortExperiment, error };
   }
   ```
