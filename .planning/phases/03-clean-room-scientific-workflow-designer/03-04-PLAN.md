Implement the user-approved local-only proposal editing and dirty-context contract without treating health as local edit permission or inventing an existing caller.

Output: a distinct current-user AppData proposal store, explicit local editability hook, typed board-owned context picker/resolver, accessible Save/Discard/Keep editing flow, and automated failure/authority coverage.
</objective>
