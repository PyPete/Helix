# UX-01 Workspace Board Contract

## Scope and authority

This is a bounded prototype-harness contract, not a primary-workspace implementation or a promotion decision. The board is an independently authored, proposal/read-model presentation over Agent-backed scientific records. The local Helix Agent remains the only authority that can address drivers or apply capability, safety, lease, resource, budget, and termination validation (D-05).

When Agent evidence is held, reconciling, faulted, or uncertain, the harness must fail closed: pointer actions, keyboard actions, shortcuts, inspector edits, and context-changing routes are read-only (D-06). It must show a persistent, non-authorizing reconciliation strip with the relevant state, evidence, and recovery route; it must not resemble an execution, acknowledgement, or confirmation control (D-07). A dirty draft must resolve Save, Discard, or Keep editing before a revision, route, or procedure change; Keep editing retains the current context (D-08).

## Boundary record

- **D-05:** All six views are proposal/read-model evidence only; no view can dispatch, approve, or confirm physical execution.
- **D-06/D-07:** The harness derives one fail-closed read-only policy from Agent evidence and exposes only evidence/recovery routes while nonhealthy or uncertain.
- **D-08:** Context changes are resolver-gated and never silently save, retarget, reroute, reassign, or publish a draft.
- **D-09:** Exact immutable identities, published/approved revision evidence, frozen references, sample custody, and lineage remain visible rather than being replaced by board-local labels.
- **D-01/D-04:** Phase 7 receives this single, original workflow-board direction; cards and graph navigation are not alternate primary modes. Phase 2.1 does not make the board primary.

## Phase 7 handoff

Phase 7 must implement the final primary-workspace board and may evaluate final promotion only after its future explicit approval gate. This contract records the bounded source bindings needed by that work; it neither implements nor promotes the workspace.
