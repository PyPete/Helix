## Scientific contract proposed for approval in 02-01

These are planner choices under Context discretion, not invented laboratory safety rules. Obtain explicit scientist acceptance in 02-01 before stabilizing contracts/schema. A rejection pauses dependent plans; revise affected plans rather than guessing.

- Identifiers: server-generated UUID aggregate/revision/sample/transformation/manifest IDs. Draft token is a monotonically increasing integer; publication sequence and stream position are distinct integers. One draft per aggregate, based on latest publication; viewing historical publications never changes it. `Create draft from revision` copies historical content into the single active draft through explicit expected-token save, retains source provenance, and does not reset its latest base.
- Apparatus catalog: `Vessel`, `Pump`, `Valve`, `Sensor`, `Collector`, `DeviceModule`; roles `Source`, `Transfer`, `Control`, `Observe`, `Collection`; port media `Fluid`, `Gas`, `Signal`; directions `In`, `Out`, `Bidirectional`. Non-empty component roles; port cardinality `One` or `Many`; matching medium and compatible direction required, distinct endpoints, no duplicate connection or ID. Physical loops are allowed. Required role by type: Pump/Transfer, Valve/Control, Sensor/Observe, Collector/Collection; Vessel permits Source or Collection, DeviceModule any catalog role. Device binding records discovered DeviceId separately from label; one active discovered identity cannot be claimed as multiple physical instances. Unbound components are allowed; capability assertions require a bound discovered capability.
- Units: exact case-sensitive codes `1`, `mL`, `L`, `g`, `mg`, `s`, `min`, `Cel`, `kPa`, `mL/min`; respective dimensions dimensionless, volume, mass, time, temperature, pressure, volume-rate. Store decimal values and exact code; no implicit conversion or universal UCUM claim. Procedure parameter declarations define name/dimension/required flag and optional inclusive bounds in one exact code; plans supply exactly those required parameters, matching code/dimension/bounds, with no unknown parameters. Unknown codes, NaN/infinity, duplicate names, invalid bounds are diagnostics, not automatic normalization. Transform quantities are positive when supplied; plan/constraint values may be zero or negative if declaration bounds permit.
- Device assertions: `CapabilityConstraint`, `CalibrationRecord`, `InspectionRecord`. Constraint names a discovered capability and parameter, dimension, unit and lower/upper inclusive bounds. Calibration/inspection records require observed time, source reference, recorder identity, optional measured value/unit pair, optional valid-through no earlier than observation. Reject future observation relative to Agent clock; preserve reported dates. Expiry is displayed as expired recorded assertion only; it does not supply live safety authorization or perform calibration. Catalog extensions require a new schema/catalog version, not unknown free-text semantics.
- Procedure: independently revisioned WslDocument plus typed parameter declarations and optional planned collection-step descriptors keyed to stable WSL node IDs. Each parameter declaration includes one-or-more explicit target pairs (WSL node ID, Parameters key), exact runtime numeric value type and expected unit; validate targets exist and no two declarations overlap the same target. Instantiate by deep-copying the pinned WSL and replacing only these declared parameter values with the plan's validated decimals in the declared exact unit. Preserve node/edge IDs/order and all other parameters; no string interpolation, guessed property paths or unit conversion. Validate WSL structure through the existing compiler's non-dispatch path. Apparatus connectivity is a different model. Structural edit of a pinned publication creates a distinct derived procedure aggregate with source revision reference; publish it and explicitly adopt in the plan draft. No in-place edit, hidden rebase, or automatic pin update.
- Canonical content: schema `scientific-setup/1`; UTF-8 compact JSON, ordinal recursively sorted object keys, stable-ID sorting for semantically unordered topology collections, original WSL step/edge order retained, invariant shortest decimal without trailing fractional zeros, declared timestamp fields as UTC with fixed seven fractional digits, canonical lowercase UUID strings, explicit null optional fields. JSON strings retain literal printable Unicode and escape quotation marks/backslashes/control characters, not HTML characters or forward slashes; names/labels retain exact Unicode and case. Reject duplicate JSON properties. Presentation coordinates/selection are separate draft-only metadata excluded from hash. SHA-256 lowercase hex computed on Agent. Use the pinned byte vectors below rather than generating expected digests with the production canonicalizer. Schema version is in the hashed envelope. Unknown schemas fail closed.
- Samples: explicit authenticated confirmation requires occurrence time, location and optional label, custodian and planned reference; planned reference may be absent. Agent records actor, recording time, UUID and initial event atomically. Future occurrence times are rejected; backdating is allowed and flagged as reported evidence. Relabel/move/correction append events using expected stream position. Projection uses server sequence, not occurrence time. Correction requires reason and earlier event ID in the same stream; cannot correct identity, actor, recorded time, collection-vs-transformation origin or parent links. A correction applies a complete replacement label/custody projection at its new sequence and preserves superseded evidence. No delete/retention/signature policy is introduced.
- Transformations: `Split`, `Pool`, `Processing` with non-empty operation description; at least one distinct existing parent and one new child. Quantity/unit pairs optional, explicitly marked not supplied when irrelevant; positive finite compatible dimensions when supplied; no depletion or conservation assumption. Children are always newly assigned IDs and have transformation origin, not invented collection. Parent links immutable; reject any supplied existing-child ID, self/duplicate/missing/foreign-scope links. New-child-only API makes cycles impossible by construction; prove this across concurrent writers. Lock parents in UUID order and create activity, children, edges, heads and receipt in one transaction.

## Common operation and authorization contract

Core ports use typed async results and CancellationToken. Repository methods take verified scope/actor, operation ID, expected token/position and validated domain request; no HttpContext in Core. Agent is local authority; records are scoped to the authenticated scientist SID for Phase 02, with all reference/receipt reads and writes enforced in that scope. No collaboration entitlement is silently added. Parameterized SQL, scoped repositories and scoped Agent services; singleton providers only if they open their own connections and never capture scoped services.

Operation identity is `(actor SID, operation kind, UUID operation ID)` with canonical request hash. Same key/content returns original result; changed content returns 409; another actor cannot read the receipt. Persist committed result and domain effects together. Expected failures return typed `Rejected` or `Conflict`; after commit return `Committed` receipt containing operationId, kind, resourceId, actor, recordedAt, payload. A missing receipt is `NotFound`, never evidence that an uncertain in-flight mutation did not commit. Outcome checking is read-only; retry only original identity/content after definitive absence and completion of in-flight reconciliation. Retain operation identity/form content across dock refresh/connection changes and disable duplicate mutation while uncertain.

Agent responses: 200 committed replay/read, 201 committed creation, 400 validation, 401 missing/expired session, 403 unauthorized scope, 404 missing authorized resource/receipt, 409 stale/mismatched identity/reference, 413 byte limit, 422 unknown schema or incompatible scientific semantics, 503 missing policy authority. Unhandled/5xx/connection loss on mutation remains uncertain unless a valid explicit rejection envelope proves no commit. Validate envelope structure/kind/key, not a generic JSON cast. Renderer-provided actor/hash/approval fields are rejected, not trusted.
