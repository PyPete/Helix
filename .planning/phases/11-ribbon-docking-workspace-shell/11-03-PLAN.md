| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-07 | Tampering | trendName from dataTransfer | mitigate | React escapes string children; trendName used only as string prop (ScalarTrendChart trendName, tab title, array element) — no eval, no innerHTML |
| T-11-08 | Tampering | adapterId in openDeviceTab | mitigate | adapterId comes from /devices API response (trusted local agent); used as string key and prop only |

| T-11-SC | Tampering | npm installs | accept | No new npm installs in this plan |
