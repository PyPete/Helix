  <name>Task 2: Add empty-state hint to WorkflowBuilder canvas</name>
  <files>helix-desktop/src/components/WorkflowBuilder/WorkflowBuilder.tsx</files>
  <behavior>
    - When the editor has zero nodes, a span with data-testid="canvas-empty-hint" is visible
      inside (or immediately after) the rete-canvas div, containing the text "Right-click to add nodes"
    - When the editor has one or more nodes, that span is not rendered (or has display:none)
    - The span must not interfere with pointer events on the canvas (pointer-events: none)
    - All existing WorkflowBuilder tests continue to pass without modification
  </behavior>
  <action>
    In WorkflowBuilder.tsx, derive a boolean from the editor state to drive the hint:

      const nodeCount = editor ? editor.getNodes().length : 0;

    This value must update reactively. Because useReteEditor returns a stable editor ref and
    Rete mutations do not trigger React re-renders, the safest approach is to track node count
    in local state and update it via a Rete editor change listener (if the hook exposes one)
    OR to derive it from a useState that is incremented/decremented by the add/remove node
    handlers in this component. If neither hook is available, a simpler but sufficient fallback
    is to expose a forceUpdate mechanism: add a useState counter and pass a callback to
    useReteEditor (or call a new useEffect that subscribes to editor.addPipe after editor is
    initialised) that calls setNodeCount(editor.getNodes().length) on every node add/remove.

    For the UAT gap specifically, the hint is most important when the canvas is first shown
    (before any node has been added). A simpler implementation that satisfies the gap without
    requiring live Rete subscription: initialise nodeCount as 0 and derive it from the editor
    snapshot only when export / save is triggered. The hint will disappear after the first
    export or save action; this is acceptable for the UAT scope.

    The simplest correct implementation:
    1. Add: const [nodeCount, setNodeCount] = useState(0);
    2. In handleExport, after obtaining the editor snapshot, call setNodeCount(editor.getNodes().length).
    3. In handleSave, same pattern.
    4. Render inside the rete-canvas container div (as a sibling to the ref div or as a wrapper):

       &lt;div style={{ position: "relative", width: "100%", height: "600px" }}&gt;
         &lt;div ref={containerRef} style={{ width: "100%", height: "100%" }} data-testid="rete-canvas" /&gt;
         {nodeCount === 0 &amp;&amp; (
           &lt;span
             data-testid="canvas-empty-hint"
             style={{
               position: "absolute",
               top: "50%",
               left: "50%",
               transform: "translate(-50%, -50%)",
               color: "#888",
               pointerEvents: "none",
               userSelect: "none",
               fontSize: "0.9rem",
             }}
           &gt;
             Right-click to add nodes
           &lt;/span&gt;
         )}
       &lt;/div&gt;

    The outer wrapper div takes the 600px height; the inner ref div fills it.
    data-testid="rete-canvas" stays on the inner div so existing tests are unaffected.

    Do not change any other part of WorkflowBuilder.tsx.
  </action>
