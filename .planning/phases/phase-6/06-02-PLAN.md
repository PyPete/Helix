    **HandleClientAsync(WebSocket ws, CancellationToken ct)** — called by Program.cs WebSocket middleware:
    - Generate clientId: `var clientId = Guid.NewGuid().ToString("N");`
    - Add to dict: `_clients[clientId] = ws;`
    - try block: receive loop — `var buffer = new byte[1024]; while (!ct.IsCancellationRequested) { var result = await ws.ReceiveAsync(buffer, ct); if (result.MessageType == WebSocketMessageType.Close) break; }`
    - finally block: `_clients.TryRemove(clientId, out _); if (ws.State == WebSocketState.Open) await ws.CloseAsync(WebSocketCloseStatus.NormalClosure, "done", CancellationToken.None);`

    **BroadcastLoopAsync(CancellationToken ct)** — private async Task:
    - `await foreach (var evt in emitter.Events.ReadAllAsync(ct))`
    - `var json = JsonSerializer.Serialize(evt, new JsonSerializerOptions { PropertyNamingPolicy = JsonNamingPolicy.CamelCase });`
    - `var bytes = Encoding.UTF8.GetBytes(json);`

    - `catch (OperationCanceledException) { break; }`
