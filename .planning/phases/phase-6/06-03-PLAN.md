```csharp
public CompilationResult Compile(WslDocument document, DeviceRegistry deviceRegistry)
{
    var diagnostics = new List<CompilationDiagnostic>();
    ValidateSchema(document, diagnostics);
    ValidateGraph(document, diagnostics);
    ValidateNodeParameters(document, diagnostics);
    ValidateDeviceBindings(document, deviceRegistry, diagnostics);
    ValidateVariableReferences(document, diagnostics);
    if (diagnostics.Any(d => d.Severity == DiagnosticSeverity.Error))
        return CompilationResult.Failed(diagnostics);
    var definition = new RunspaceDefinition(...Nodes: document.Nodes, Edges: document.Edges...);
    return CompilationResult.Succeeded(definition, diagnostics);
}
```

    - `private static List<WslNode> InjectSafetyEnvelope(IReadOnlyList<WslNode> nodes, ISafetyEngine safetyEngine, List<CompilationDiagnostic> diagnostics)`
    - Snapshot violations: `var violations = safetyEngine.GetViolationsAsync().GetAwaiter().GetResult().ToList();`
    - For each violation, create a guard node: `new WslNode(NodeId: $"safety-guard-{violation.RuleId}", Label: $"Safety: {violation.Description}", NodeType: "SafetyGuard", Parameters: new Dictionary<string, object?> { ["ruleId"] = violation.RuleId, ["severity"] = violation.Severity.ToString(), ["description"] = violation.Description })`
    - Add each guard node to the front of the nodes list (prepend before first non-entry node)
    - Add `diagnostics.Add(new CompilationDiagnostic(DiagnosticSeverity.Warning, $"Safety guard injected for rule '{violation.RuleId}': {violation.Description}", null, "WSL050"))`
    - Return the modified nodes list (do NOT modify the original IReadOnlyList)
    - Do NOT call RegisterInterlock, UnregisterInterlock, or TriggerEmergencyStopAsync

    **2. ExpandLoopNodes** — new private static method:
    - `private static (List<WslNode> nodes, List<WslEdge> edges) ExpandLoopNodes(IReadOnlyList<WslNode> nodes, IReadOnlyList<WslEdge> edges, List<CompilationDiagnostic> diagnostics)`
    - Find all nodes where `NodeType == "Loop"` (case-insensitive)
    - For each loop node: read `iterations = (int)(node.Parameters.GetValueOrDefault("iterations") ?? 1)`
    - If iterations < 1: add diagnostic WSL051 warning "Loop node has iterations < 1; treating as 1" and set to 1
    - Create N copies of body nodes (nodes whose incoming edges come from the loop node, excluding the loop node itself) with suffixed IDs: `{originalId}-loop-{i}`
    - Wire edges: remove the loop node; connect preceding node -> first copy, copy[i] -> copy[i+1], last copy -> following node
    - Add diagnostic WSL052 info "Loop node '{id}' expanded to {N} iterations"
    - If loop node has no identifiable body (no outgoing edges within the loop), add WSL053 warning and leave as-is

    **3. FlattenBranchNodes** — new private static method:
    - `private static (List<WslNode> nodes, List<WslEdge> edges) FlattenBranchNodes(IReadOnlyList<WslNode> nodes, IReadOnlyList<WslEdge> edges, List<CompilationDiagnostic> diagnostics)`
    - Find all nodes where `NodeType == "Branch"` (case-insensitive)
    - For each branch node: find all outgoing edges; label first as "true" condition, second as "false" condition using `Parameters` extension `new Dictionary<string, object?>(edge's existing params) { ["condition"] = "true" }`
    - Create conditional edges by producing new WslEdge records with a Condition parameter (check WslEdge fields — add `Condition` if not present, or store in metadata)
    - If WslEdge does not have a condition field, emit a WslNode of type "ConditionalGateway" with condition parameter between Branch and its targets
    - Add diagnostic WSL054 info "Branch node '{id}' flattened to conditional edges"

    **4. FlattenParallelNodes** — new private static method:
    - `private static (List<WslNode> nodes, List<WslEdge> edges) FlattenParallelNodes(IReadOnlyList<WslNode> nodes, IReadOnlyList<WslEdge> edges, List<CompilationDiagnostic> diagnostics)`
    - Find all nodes where `NodeType == "Parallel"` (case-insensitive)
    - For each parallel node: insert a fork node (NodeType="ParallelFork") before it and a join node (NodeType="ParallelJoin") after it
    - Wire: preceding -> fork -> [branch1, branch2, ...] each -> join -> following
    - Add diagnostic WSL055 info "Parallel node '{id}' expanded to fork-join structure"
