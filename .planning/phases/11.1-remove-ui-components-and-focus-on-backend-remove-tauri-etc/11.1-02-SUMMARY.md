## What was done

**Task 1 — gRPC PauseRunspace/ResumeRunspace wiring (GAP 4)**

`AgentGrpcService.PauseRunspace` and `ResumeRunspace` in
`Helix.Orchestration.Agent/gRPC/Server/AgentGrpcService.cs` replaced the
`await Task.CompletedTask` + hardcoded stub responses with real delegation:

- Look up the runspace via `_runspaceManager.Get(request.RunspaceId)`.
- If `null`: return `CommandAck { Success = false, Message = "Runspace '{id}' not found" }`.
- If found: call `await rs.PauseAsync(ctx.CancellationToken)` / `rs.ResumeAsync(...)` in a try/catch.
  - On success: return `{ Success = true, Message = "Paused" }` / `{ ..., Message = "Resumed" }`.
  - On exception: return `{ Success = false, Message = ex.Message }`.

Five tests created in `tests/Helix.Orchestration.Agent.Tests/gRPC/AgentGrpcServiceTests.cs` using Moq:
- `PauseRunspace_ValidId_CallsPauseAsyncAndReturnsSuccess` — verifies delegation and `Success=true`.
- `PauseRunspace_UnknownId_ReturnsFailureWithNotFound` — `null` return from manager.
- `PauseRunspace_PauseAsyncThrows_ReturnsFailure` — exception propagation to `CommandAck`.
- `ResumeRunspace_ValidId_CallsResumeAsyncAndReturnsSuccess` — verifies delegation and `Success=true`.
- `ResumeRunspace_UnknownId_ReturnsFailureWithNotFound` — `null` return from manager.

All 5 tests pass. A minimal `FakeServerCallContext` (file-scoped class) is provided inline.

## Deviations from plan

- Plan suggested `Grpc.Core.Testing.TestServerCallContext`; that package is not in the test project. Used an inline `file sealed class FakeServerCallContext : ServerCallContext` instead.
