## What was done

**Task 1 — ITrendProvider implementations (GAP 1)**

All six previously-stubbed methods in `InMemoryTrendProvider.cs` now return working implementations:

- `GetScalarTrend<T>` — backed by a new `ConcurrentDictionary<string, object> _scalarTrends`; creates and returns `InMemoryScalarTrend<T>(name, 100)`.
- `GetTrend<T>` — delegates to `GetScalarTrend<T>().Window` so both accessors share the same `TrendWindow<T>`.
- `PushScalar<T>` — now also pushes into the `InMemoryScalarTrend<T>` instance, keeping `_scalarLatest` and `Window` in sync.
- `GetImageTrend` — backed by `ConcurrentDictionary<string, InMemoryImageTrend>`. New `public sealed class InMemoryImageTrend` wraps a `Subject<ImageFrame>`, exposes `LatestFrame`, and has a `Push(ImageFrame)` method.
- `GetVideoTrend` — same pattern; `InMemoryVideoTrend` wraps `Subject<VideoSegment>`, exposes `LatestSegment`, and has `Push(VideoSegment)`.
- `GetDerivedTrend` / `RegisterDerivedTrend` — backed by `ConcurrentDictionary<string, InMemoryDerivedTrend>`. New `public sealed class InMemoryDerivedTrend` stores the `DerivedTrendDefinition` and exposes `SourceTrendIds`.

`GetAllTrends`, `GetTrendsByKind`, `IsTrendAvailableAsync`, `GetAllTrendNames`, and `Dispose` updated to cover all four new dictionaries.

5 new tests added in `InMemoryTrendProvidersTests.cs`; all 7 tests pass.

**Task 2 — Variable substitution wiring + cooperative pause/resume (GAPs 2, 3)**

*GAP 2 — VariableSubstitution in BFS loop (`Program.cs`):*
- `IWorkflowStateStore`, `IGlobalStateStore`, and `ICapabilityInvoker` now resolved from DI in the `RunspaceManager` factory closure.
- `VariableSubstitution.SubstituteParametersAsync` called before `capRegistry.InvokeAsync` for every Step/DeviceAction node; both the invocation and the Delay branch use `substitutedParams`.

*GAP 3 — Cooperative pause/resume (`InMemoryRunspace.cs`):*
- Added `SemaphoreSlim? _pauseGate` field.
- `PauseAsync`: sets `Status = Paused`, creates `_pauseGate = new SemaphoreSlim(0, 1)`.
- `ResumeAsync`: sets `Status = Running`, calls `_pauseGate?.Release()`, nulls the gate.
- `CheckPauseAsync(token)`: awaits the gate if set — called at the top of each BFS iteration.
- `AbortAsync`: releases the gate before cancelling so the loop can observe the `CancellationToken`.
- `DisposeAsync`: disposes the gate.

3 new tests in `InMemoryRunspaceTests.cs`; all pass.
