# Plan 11.1-03 Summary — SiteServer Backend GAPs 5-8

**Status:** COMPLETE  
**Commit:** `89b940a`  
**Tests:** 45/45 SiteServer · 31/31 Agent

## GAPs Closed

### GAP 5 — WSL Compiler Integration in ExperimentEndpoints
`ExperimentEndpoints.MapPost` now accepts raw `WslSource` JSON, deserializes it as `WslDocument`, and calls `IWslCompiler.Compile(document, deviceRegistry)`. Compilation failures return `400 BadRequest` with diagnostics; success produces a typed `RunspaceDefinition` passed to `SubmitExperimentAsync`. `IWslCompiler` registered as singleton in `Program.cs`.

### GAP 6 — gRPC ListDevices RPC
- Proto: added `ListDevicesRequest`, `DeviceInfo`, `ListDevicesResponse` messages and `rpc ListDevices` to `AgentControl`.
- `AgentGrpcService`: added `DeviceRegistry` field; `ListDevices` override iterates `GetAllDevices()` and maps to `DeviceInfo` protos.
- `IAgentProxy`: `GetRegisteredDevices()` → `GetRegisteredDevicesAsync(CancellationToken)`.
- `IAgentControlClient` / `GrpcAgentControlClient`: added `ListDevicesAsync`.
- `GrpcAgentProxy.GetRegisteredDevicesAsync`: calls `client.ListDevicesAsync`, maps `DeviceInfo` → `DeviceDescriptorDto`.
- `SimAgentProxy`: returns hardcoded sim devices from `GetRegisteredDevicesAsync`.

### GAP 7 — Fumehood Status from Live Agent Query
`FumehoodEndpoints` handler is now `async Task<IResult>`. It calls `await agentProxy.GetRegisteredDevicesAsync(ct)` and sets `status = devices.Any() ? "online" : "offline"`. Queries `IExperimentRepository.GetAllAsync` for a running experiment name to populate `ActiveExperimentName`.

### GAP 8 — Campaign Persistence to PostgreSQL
`CampaignManager` accepts `ICampaignRepository` as a third constructor parameter. All CRUD methods are now async: `CreateAsync`, `GetByIdAsync`, `GetAllAsync`, `DeleteAsync`, and `StartAsync` write through to the repository via `ToCampaignRecord` / `FromCampaignRecord` helpers.
