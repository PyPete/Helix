## MDX 3 Anti-Patterns — Do Not Repeat

| Pattern | How It Manifests | Fix |
|---------|-----------------|-----|
| `{id}` in table cells | `ReferenceError: id is not defined` during SSR | HTML-encode: `&#123;id&#125;` |
| `{var}` in prose | Same SSR error | Escape with backslash: `\{var\}` |
| `<TypeParam>` in prose | JSX element parse error | Wrap in backticks |
| Unescaped C# interpolation strings | Build breaks in MDX context | Always use code fences or escape |
