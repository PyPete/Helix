## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] @docusaurus/theme-mermaid not installed**
- **Found during:** Task 1 - first build attempt
- **Issue:** Docusaurus 3 preset-classic does NOT bundle `@docusaurus/theme-mermaid`. The config references it in `themes: ['@docusaurus/theme-mermaid']` but it was not present in `node_modules`.
- **Fix:** Ran `npm install @docusaurus/theme-mermaid` in docs-site/
- **Files modified:** `docs-site/package.json`, `docs-site/package-lock.json`
- **Commit:** 3bc3153

**2. [Rule 1 - Bug] Deprecated onBrokenMarkdownLinks top-level config**
- **Found during:** Task 1 - first build attempt warning
- **Issue:** The plan specified `onBrokenMarkdownLinks: "warn"` as a top-level config option. Docusaurus 3.10.1 deprecates this in favor of `markdown.hooks.onBrokenMarkdownLinks`.
- **Fix:** Removed top-level `onBrokenMarkdownLinks` and set `markdown.hooks.onBrokenMarkdownLinks: 'warn'` instead.
- **Files modified:** `docs-site/docusaurus.config.ts`
- **Commit:** 3bc3153

**3. [Rule 1 - Bug] Home page linked to deleted /docs/intro**
- **Found during:** Task 1 - second build attempt
- **Issue:** The generated `src/pages/index.tsx` hard-coded a link to `/docs/intro` which was deleted (per plan). Build failed with broken link error.
- **Fix:** Updated `src/pages/index.tsx` to link to `/docs/developer/intro` and `/docs/operator/intro` with appropriate button labels. Also updated page title and description to use `siteConfig.title` and `siteConfig.tagline`.
- **Files modified:** `docs-site/src/pages/index.tsx`
- **Commit:** 3bc3153
