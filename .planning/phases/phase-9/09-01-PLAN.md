<task type="auto">
  <name>Task 2: Add docs-site CI build job to .github/workflows/ci.yml</name>
  <files>.github/workflows/ci.yml</files>
  <action>
    Add a new job named "docs" to .github/workflows/ci.yml. The existing jobs are: build-and-test, dashboard, code-quality, tauri-build, release, publish.

    Insert the docs job after the "dashboard" job. The job has no needs dependency (runs in parallel with build-and-test):

      docs:
        name: Docs Build
        runs-on: ubuntu-latest
        steps:
          - name: Checkout
            uses: actions/checkout@v4
          - name: Setup Node.js
            uses: actions/setup-node@v4
            with:
              node-version: 20
              cache: npm
              cache-dependency-path: docs-site/package-lock.json
          - name: Install dependencies
            working-directory: docs-site
            run: npm ci
          - name: Build docs
            working-directory: docs-site
            run: npm run build

    Do not add a deployment step — deployment to GitHub Pages is out of scope for CI (deploy is a separate manual workflow or gh-pages branch push).

    The cache-dependency-path must point to docs-site/package-lock.json (generated during Task 1 scaffold).
  </action>
