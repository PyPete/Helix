# Phase 6.3 Plan 02: Fix DeviceRegistry.tsx fetch /health -> /devices (C1) Summary

**One-liner:** Replaced `GET /health` plain-text fetch with `GET /devices` JSON array fetch and rewrote 4 tests to match the new response shape.

## What Was Done

DeviceRegistry.tsx was calling `GET /health` (returning plain text "Healthy"/"Degraded") and synthesising a phantom `{ adapterId: "agent" }` row via `mapHealthToAdapters`. This was replaced with the correct `GET /devices` endpoint which returns `{ adapterId: string, capabilities: string[] }[]`.

### Changes

**helix-desktop/src/components/DeviceRegistry.tsx**
- Removed `mapHealthToAdapters` function (was fabricating a phantom "agent" row from health text)
- Added `mapDevicesToAdapters(data: { adapterId: string; capabilities: string[] }[])` — maps each entry to `DeviceAdapter` with `healthy: true, message: "registered"` (synthetic values; presence in /devices response implies availability)
- Changed `fetch(\`${agentBaseUrl}/health\`)` to `fetch(\`${agentBaseUrl}/devices\`)`
- Changed `res.text()` to `res.json()`, removed intermediate `{ status?: string }` wrapping

**helix-desktop/src/components/DeviceRegistry.test.tsx**
- Test 2: renamed to "renders adapter list when fetch returns devices array"; mock now returns `json: () => Promise.resolve([{ adapterId: "simulator", capabilities: ["simulator.SetFlow"] }])`; asserts `screen.getByText(/simulator/i)` and `screen.getByText("Manual Control")`
- Test 5: renamed to "shows No adapters found when fetch returns empty array"; mock returns `json: () => Promise.resolve([])`; asserts `screen.getByText(/No adapters found/i)`
- Tests 1, 3, 4: assertions unchanged; test 3 mock simplified to `{ ok: false, status: 503 }` (no body method needed, error path short-circuits before json())
- TDD protocol followed: RED confirmed (2 failures with old component), GREEN confirmed (5/5 pass after fix)
