# Phase 6.4 Plan 02: FumehoodEndpoints + SiteOverviewPage Live API Fetch Summary

One-liner: Added GET /api/fumehoods MinimalAPI endpoint in SiteServer and replaced SiteOverviewPage's hardcoded PLACEHOLDER_FUMEHOODS array with a live useEffect fetch, wired via baseUrl prop.

## What Was Done

### Task 1: FumehoodEndpoints.cs + Program.cs

Created `Helix.Orchestration.SiteServer/Endpoints/FumehoodEndpoints.cs` following the DeviceEndpoints pattern:
- Defines `FumehoodDto` record (Id, Name, Status, ActiveExperimentName, LastSeenAt)
- Maps `GET /api/fumehoods` reading `MqttBridgeOptions.FumehoodId` from DI
- Calls `IAgentProxy.GetRegisteredDevices()` in a try/catch to determine reachability status (idle/offline)
- Returns `Results.Ok(new[] { dto })`

Added `app.MapFumehoodEndpoints();` after `app.MapCampaignEndpoints()` in Program.cs.

### Task 2: SiteOverviewPage.tsx + test + App.tsx

Updated `helix-dashboard/src/pages/SiteOverviewPage.tsx`:
- Removed the `PLACEHOLDER_FUMEHOODS` const array
- Added `useState`, `useEffect` from React
- Added `SiteOverviewPageProps { baseUrl: string }` interface and updated function signature
- Replaced hardcoded data with `useState<FumehoodStatus[]>([])` and a `useEffect` fetch hook
- Added loading/error display (plain text nodes)

Updated `helix-dashboard/src/pages/SiteOverviewPage.test.tsx`:
- Added `beforeEach`, `afterEach`, `vi` from vitest; `waitFor` from @testing-library/react
- Added `vi.stubGlobal("fetch", ...)` mock returning two fumehood entries per test
- Updated all 6 `render()` calls to pass `baseUrl="http://localhost:5090"`
- Rewrote 4 data-dependent tests with `await waitFor(...)` for async fetch resolution
- Renamed "renders at least 3 fumehood cards" to "renders fumehood cards from API"

Updated `helix-dashboard/src/App.tsx`:
- Changed `<SiteOverviewPage />` to `<SiteOverviewPage baseUrl={baseUrl} />`
