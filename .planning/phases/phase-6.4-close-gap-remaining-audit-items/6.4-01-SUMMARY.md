# Phase 6.4 Plan 01: Infrastructure Gaps — Postgres Env, CI Vitest, gRPC Service Summary

Closed three v0.1 audit gaps: helix-siteserver missing Postgres connection string, helix-desktop Vitest tests absent from CI, and Agent gRPC server not implemented.

## Tasks Completed

### Task 1: docker-compose.yml — helix-siteserver env fix + helix-agent Http1AndHttp2

Three targeted additions to docker-compose.yml:

1. Added `Kestrel__Endpoints__Http__Protocols: Http1AndHttp2` to helix-agent environment block (after `Kestrel__Endpoints__Http__Url`)
2. Added `ConnectionStrings__HelixOrchestration` to helix-siteserver environment block with the same Postgres connection string pattern as helix-agent
3. Added `postgres: condition: service_started` to helix-siteserver depends_on block

### Task 2: ci.yml — helix-desktop-test job

Added new `helix-desktop-test:` job after the `dashboard:` job and before `docs:`, mirroring the dashboard job structure but without a build step. Uses:
- `actions/setup-node@v4` with node-version 20 and npm cache
- `npm ci` install
- `npm test -- --run` for Vitest headless execution

### Task 3: AgentGrpcService.cs + Program.cs

Created `Helix.Orchestration.Agent/gRPC/Server/AgentGrpcService.cs` implementing all five RPC methods from the `agent_control.proto` service definition:
- `SubmitExperiment` — deserializes RunspaceDefinition and calls `_runspaceManager.CreateAsync`
- `GetRunspaceStatus` — looks up runspace by ID and returns current status
- `AbortRunspace` — calls `_runspaceManager.AbortAsync`
- `PauseRunspace` / `ResumeRunspace` — stub implementations returning "not implemented" message

Updated `Program.cs`:
- Added `using Helix.Orchestration.Agent.GrpcServer;`
- Added `builder.Services.AddGrpc();` before `var app = builder.Build()`
- Added `app.MapGrpcService<AgentGrpcService>();` after `app.Build()` before other Map* calls
